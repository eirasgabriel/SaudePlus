# API SaúdePlus

A base Spring Boot está estruturada, mas ainda não há endpoints implementados.
O servidor está configurado para a porta 8080 por padrão.

Ao implementar cada recurso, documentar método e caminho, autenticação e
permissões, formato de entrada, respostas e códigos de erro. Manter este contrato
alinhado aos DTOs do back-end e às chamadas em `frontend/src/features/`.
