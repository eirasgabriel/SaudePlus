# Back-end SaúdePlus

Estrutura inicial, ainda sem framework, banco de dados ou endpoints implementados.
Não há comando de execução neste estágio.

Consulte [a arquitetura](../docs/arquitetura.md) para as responsabilidades de
`src/config`, `src/database`, `src/middlewares`, `src/modules` e `tests`.

Ao definir a stack, adicionar aqui o manifesto de dependências, os comandos de
desenvolvimento/testes e um `.env.example` com as variáveis realmente utilizadas,
sem credenciais reais. Documentar os endpoints em [docs/api.md](../docs/api.md).
